MATERI 3

1. Computer and Mobile Devices
Computer and mobile devices adalah berbagai perangkat yang menggunakan teknologi komputer untuk membantu manusia melakukan pekerjaan, mengolah informasi, berkomunikasi, maupun hiburan.
Contohnya:
Laptop
Tablet
Desktop/PC
Server
Smartphone
Kamera digital
E-book reader
Wearable device
Perangkat game
Embedded computer
Jadi, komputer tidak hanya berbentuk PC atau laptop. Banyak perangkat sehari-hari juga sebenarnya memiliki sistem komputer di dalamnya. TTI#3 (1).pdf
2. Mobile Computer dan Desktop
A. Mobile Computer
Mobile computer adalah komputer yang dirancang agar mudah dibawa dari satu tempat ke tempat lain.
Contohnya adalah laptop dan beberapa jenis perangkat komputer portabel lainnya.
Keuntungan utamanya adalah mobilitas. Kita dapat menggunakannya di rumah, kampus, kantor, atau tempat lainnya.
B. Personal Computer (PC)
PC adalah komputer yang dapat melakukan berbagai aktivitas sendiri, mulai dari:
Input → Processing → Output → Storage
Contohnya:
Memasukkan data menggunakan keyboard (input)
CPU mengolah data (processing)
Hasil muncul di monitor (output)
Data disimpan di SSD/HDD (storage)
PC dapat berupa komputer desktop maupun komputer bergerak. TTI#3 (1).pdf
3. Server
Server adalah komputer yang bertugas menyediakan layanan kepada komputer atau perangkat lain yang terhubung dalam jaringan.
Contoh sederhananya:
Komputer pengguna → jaringan → Server
Misalnya ketika kamu membuka sebuah website, komputer/server menyediakan data website tersebut kepada perangkatmu.
Virtualisasi
Virtualisasi adalah teknik untuk membagi atau menggabungkan sumber daya komputasi.
Dalam virtualisasi server, satu server fisik dapat digunakan untuk menjalankan beberapa server virtual.
Server Farm
Server farm adalah kumpulan beberapa server yang ditempatkan di satu lokasi. TTI#3 (1).pdf
4. Terminal
Terminal adalah komputer atau perangkat yang biasanya memiliki kemampuan pemrosesan terbatas dan digunakan untuk mengirim atau menerima informasi dari server/komputer host. TTI#3 (1).pdf
Ada beberapa contoh penting:
Thin Client
Komputer yang bentuknya mirip desktop tetapi memiliki komponen dan kemampuan pemrosesan yang terbatas.
ATM
ATM (Automated Teller Machine) adalah terminal perbankan swalayan.
Contohnya digunakan untuk:
Mengambil uang
Mengecek informasi rekening
Melakukan transaksi perbankan tertentu
ATM terhubung dengan komputer host melalui jaringan.
Kios Swalayan
Kios swalayan adalah terminal mandiri yang biasanya menggunakan layar sentuh agar pengguna dapat berinteraksi dengan sistem. TTI#3 (1).pdf
5. Supercomputer
Supercomputer atau superkomputer adalah komputer yang memiliki kemampuan pemrosesan sangat tinggi.
Menurut materi, superkomputer merupakan komputer yang paling cepat, paling kuat, dan paling mahal, serta mampu memproses banyak triliunan instruksi dalam satu detik. TTI#3 (1).pdf
Jadi, superkomputer bukan ditujukan untuk penggunaan sehari-hari seperti mengetik atau bermain game biasa, tetapi untuk pekerjaan yang membutuhkan kemampuan komputasi sangat besar.
