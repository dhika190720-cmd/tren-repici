TREN TEKNOLOGI INFORMASI2026/2027

MATERI 1

Materi ini membahas pemahaman dasar mengenai teknologi informasi dan komputer, meliputi:

  • Mengenal berbagai jenis perangkat, seperti laptop, tablet, komputer desktop, dan server.
  • Memahami fungsi komputer, smartphone, kamera digital, pemutar media digital, e-book reader, perangkat wearable, serta perangkat untuk bermain gim.
  • Mengetahui keterkaitan antara data dengan informasi.
  • Mengenal berbagai macam perangkat yang digunakan untuk memasukkan data atau perintah ke komputer.
  • Memahami perbedaan Internet dan Web serta hubungan antara webpage, website, dan web server.
  • Menjelaskan kegunaan browser, search engine, dan media sosial.
  • Mengenali berbagai ancaman dalam penggunaan teknologi, seperti virus dan malware, serta memahami masalah privasi, kesehatan, dan lingkungan.
  • Mengetahui perbedaan antara sistem operasi dengan aplikasi.
  • Memahami perbedaan teknologi yang menggunakan kabel dan teknologi nirkabel serta alasan jaringan komputer digunakan.
  • Mengetahui penerapan teknologi di berbagai bidang, seperti pendidikan, pemerintahan, keuangan, perdagangan, hiburan, kesehatan, sains, penerbitan, dan manufaktur.

1. Teknologi Saat Ini (Today's Technology)

Literasi Digital

Perkembangan teknologi yang berlangsung dengan cepat membuat setiap orang perlu terus mempelajari hal-hal baru agar tetap mampu menggunakan teknologi dengan baik.

Pengertian Literasi Digital

Literasi digital merupakan kemampuan seseorang dalam memahami dan menggunakan teknologi, seperti komputer, perangkat mobile, internet, web, serta teknologi digital lainnya.

2. Komputer dan Proses Kerjanya (Computers)

Pengertian Komputer

Komputer merupakan perangkat elektronik yang bekerja berdasarkan instruksi atau perintah yang tersimpan di dalam memorinya.

Tahapan Kerja Komputer

Secara umum, komputer bekerja melalui tiga proses utama:

  • Input → komputer menerima data atau perintah dari pengguna.
  • Processing → data yang diterima kemudian diolah oleh komputer.
  • Output → hasil pengolahan data ditampilkan sebagai informasi.

3. Data dan Informasi (Data and Information)

Perangkat Input

Perangkat input digunakan untuk memasukkan data, perintah, atau informasi ke dalam komputer.

Pointing Device adalah perangkat yang digunakan untuk menggerakkan dan mengatur posisi pointer pada layar. Contohnya adalah mouse dan touchpad.

Selain itu, terdapat perangkat input lainnya, seperti:

  • Mikrofon → digunakan untuk memasukkan suara atau audio.
  • Webcam/kamera → digunakan untuk mengambil dan memasukkan gambar maupun video.

Memori dan Media Penyimpanan

Memori (RAM) merupakan komponen yang digunakan untuk menyimpan sementara instruksi dan data yang sedang diperlukan oleh komputer ketika menjalankan suatu proses.

Media penyimpanan (storage media) digunakan untuk menyimpan data, instruksi, dan informasi agar dapat digunakan kembali dalam jangka panjang.

Perangkat penyimpanan (storage device) adalah perangkat yang berfungsi untuk menyimpan atau mengambil data dari media penyimpanan.

4. Konsep Web (The Web)

World Wide Web (Web)

World Wide Web atau Web merupakan kumpulan informasi yang tersedia di seluruh dunia dan dapat diakses melalui koneksi Internet.

Webpage

Webpage adalah sebuah dokumen atau halaman digital yang dapat diakses melalui Web.

Website

Website merupakan sekumpulan webpage yang saling terhubung dan biasanya memiliki tujuan atau topik tertentu.

Web Server

Web server adalah komputer atau sistem yang menyimpan halaman website dan bertugas mengirimkan halaman tersebut kepada perangkat pengguna ketika diminta.

5. Browser, Search Engine, dan Jejaring Sosial

Browser adalah aplikasi yang digunakan untuk membuka dan menjelajahi berbagai halaman di Web.

Search engine merupakan layanan yang membantu pengguna menemukan informasi tertentu di Internet berdasarkan kata kunci yang dimasukkan.

Jejaring sosial online adalah platform yang memungkinkan pengguna untuk berkomunikasi, berinteraksi, dan berbagi berbagai macam informasi melalui Internet
