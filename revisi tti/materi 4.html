MATERI 4

1. Program, Application, dan Operating System
Program/software adalah kumpulan instruksi yang saling berhubungan dan digunakan untuk memberi tahu komputer tugas apa yang harus dilakukan dan bagaimana melakukannya.
Application (app) adalah program yang dirancang untuk membantu pengguna menjadi lebih produktif atau melakukan tugas pribadi.
Operating System (OS) adalah sekumpulan program yang mengatur dan mengoordinasikan aktivitas antara perangkat keras komputer/perangkat mobile. DC17_Ch04- PDF_7af31371db1f3261fe821efa0c691d68.pdf
Software dapat diperoleh dalam berbagai bentuk, seperti retail, custom, web app, mobile app, mobile web app, shareware, freeware, open source, dan public domain. DC17_Ch04- PDF_7af31371db1f3261fe821efa0c691d68.pdf
2. Productivity Applications
Productivity applications digunakan untuk membantu pekerjaan menjadi lebih efektif dan efisien, baik untuk sekolah, pekerjaan, maupun kehidupan sehari-hari. DC17_Ch04- PDF_7af31371db1f3261fe821efa0c691d68.pdf
Contohnya:
a. Word Processing
Digunakan untuk membuat dan mengedit dokumen. Keuntungannya adalah tulisan dapat diubah dan diperbaiki dengan mudah. DC17_Ch04- PDF_7af31371db1f3261fe821efa0c691d68.pdf
b. Presentation Software
Digunakan untuk membuat presentasi visual untuk menyampaikan ide, pesan, dan informasi kepada suatu kelompok. DC17_Ch04- PDF_7af31371db1f3261fe821efa0c691d68.pdf
c. Spreadsheet
Digunakan untuk mengatur data dalam baris dan kolom serta melakukan perhitungan. DC17_Ch04- PDF_7af31371db1f3261fe821efa0c691d68.pdf
d. Database
Database merupakan kumpulan data yang diatur sehingga dapat diakses, dicari, dan digunakan. Database software digunakan untuk membuat dan mengelola database. DC17_Ch04- PDF_7af31371db1f3261fe821efa0c691d68.pdf
e. Note Taking
Digunakan untuk mencatat teks, tulisan tangan, gambar, sketsa, foto, dan tautan pada suatu halaman. DC17_Ch04- PDF_7af31371db1f3261fe821efa0c691d68.pdf
f. Calendar & Contact Management
Membantu pengguna mengatur jadwal, menyimpan kontak, dan membagikan informasi tersebut kepada pengguna lain. DC17_Ch04- PDF_7af31371db1f3261fe821efa0c691d68.pdf
g. Project Management
Digunakan untuk merencanakan, menjadwalkan, memantau, dan menganalisis kegiatan, sumber daya, serta biaya sebuah proyek. DC17_Ch04- PDF_7af31371db1f3261fe821efa0c691d68.pdf
h. Accounting
Membantu bisnis dalam mencatat dan melaporkan transaksi keuangan. DC17_Ch04- PDF_7af31371db1f3261fe821efa0c691d68.pdf
i. Personal Finance
Membantu pengguna mengelola keuangan pribadi, seperti mencatat pemasukan dan pengeluaran, membayar tagihan, memantau saldo, dan investasi. DC17_Ch04- PDF_7af31371db1f3261fe821efa0c691d68.pdf
Selain itu terdapat legal software, tax preparation software, document management software, dan enterprise computing untuk kebutuhan khusus. DC17_Ch04- PDF_7af31371db1f3261fe821efa0c691d68.pdf
3. Graphics and Media Software
Software ini digunakan untuk membuat, mengedit, dan mengelola gambar, foto, video, audio, serta multimedia.
Jenisnya antara lain:
CAD (Computer-Aided Design) → membantu membuat desain menggunakan komputer.
Desktop publishing → membuat berbagai publikasi.
Paint/Image editing → membuat dan mengedit gambar.
Photo editing & management → mengedit dan mengelola foto.
Video & audio editing → mengedit video dan audio. DC17_Ch04- PDF_7af31371db1f3261fe821efa0c691d68.pdf
Multimedia & Website Authoring
Multimedia authoring software menggabungkan teks, grafik, audio, video, dan animasi menjadi aplikasi interaktif.
Website authoring software membantu membuat halaman web yang dapat berisi grafik, video, audio, animasi, efek khusus, dan konten interaktif. DC17_Ch04- PDF_7af31371db1f3261fe821efa0c691d68.pdf
Media Player
Digunakan untuk melihat gambar/animasi, mendengarkan audio, dan menonton video. Sedangkan disc burning software digunakan untuk menulis data seperti teks, gambar, audio, dan video ke media disc. DC17_Ch04- PDF_7af31371db1f3261fe821efa0c691d68.pdf
